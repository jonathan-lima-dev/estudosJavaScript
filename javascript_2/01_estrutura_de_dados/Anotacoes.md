#Estrutura de dados:

Uma forma diferente dos tipos primitivos, é o tipo objeto, que é uma estrutura de dados que pode conter qualquer tipo de dado, incluindo outros objetos.

- Lista Ligada:
  Um elemento aponta para o outro.Ex: Elemento 1 > Elemento 2 > Elemento 3 > Elemento 4

- Vetores (Arrays):
  Coleção de elementos indentificados por um índice. array = [1,2,3,4,5]. Lembrando que o índice começa em 0.

- Fila(Queue): 
  Coleção de elementos onde o primeiro item da lista a entrar é o primeiro a sair. Relamente é como uma fila de mercado, banco etc.

- Pilha (Stack):
  Coleção de elementos onde o último item da lista a entrar é o primeiro a sair. Realmente como objetos empilhados um em cima do outro.

- Árvores (Tree):
  Coleção de elementos como uma árvore que tem diversas ramificações. Ex: árvore genelógica, pastas de um computador, página de site.

- Grafos (Graph):
  Coleção de elementos que possuem relações entre si. Ex: rede social, mapa de um jogo e GPS.
